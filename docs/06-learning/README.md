# Application Diagnosis Platform 学习教案

> 教学目标：以业务问题为主线，将业务对象、应用用例、领域规则、Agent Runtime、基础设施和面试表达串成一套可复述、可定位、可验证的项目认知。

## 使用方法

每课按以下流程完成：

```text
阅读教案 → 查看流程图 → 抽查关键源码 → 提出疑问
→ 完成自测 → 老师反馈 → 进入下一课 → 固化问答与验收结果
```

教案提前生成不代表课程已经完成。只有“学员疑问闭环 + 自测通过 + 能用自己的话复述”，对应课时才标记为完成。
