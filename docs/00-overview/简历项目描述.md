# 简历与面试项目描述

> [返回文档导航](../README.md)

## 一句话版本

独立实现证据驱动的应用诊断 Agent 平台，通过有界 Agent Loop、工具白名单、Evidence 引用校验、人工确认和离线评测控制 LLM 系统风险。

## 简历版本

使用 Python、FastAPI、SQLAlchemy、SQLite 和 LLM Tool Calling 独立设计应用诊断 Agent 平台；实现受轮次、工具次数和超时预算约束的 Agent Loop，以及工具 Registry、结构化输出和运行审计。建立输入脱敏、Evidence 生命周期、引用合法性校验、Knowledge 状态和人工确认闭环，并提供诊断报告、离线评测与极简界面。项目拥有 149 个自动化测试及 Phase 0A/0B/0C 一键验收。

## 面试介绍顺序

1. 为什么普通 LLM 问答不足以承担应用诊断；
2. Phase 0A 如何控制模型与工具；
3. Phase 0B 如何让结论拥有可追踪依据和人工反馈；
4. Phase 0C 如何评测、报告和演示；
5. 当前妥协与下一步真实模型评测计划。

## 深挖问题

- Strategy 白名单与 Registry 强制校验的区别；
- EvidenceDraft 为什么不能直接引用；
- Citation Policy 能证明什么、不能证明什么；
- Confirmation 为什么不覆盖模型结论；
- 报告为什么不再次调用模型。
