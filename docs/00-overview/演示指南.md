# Phase 0 离线演示指南

> [返回文档导航](../README.md)

## 一键离线演示

```powershell
uv run python scripts/demo-phase0.py
```

演示使用临时 SQLite 和 OfflineDemoLLM，不读取 `.env`、不访问网络、不产生费用。

链路：创建含敏感样例的诊断 → 脱敏 → 调用 `knowledge__search` → EvidenceDraft 落库 → 引用正式 Evidence ID → Citation Policy 校验 → 人工确认 → Markdown 报告。

输出位于 `demo-output/demo-summary.json` 和 `demo-output/diagnosis-report.md`，该目录已被 Git 忽略。

## 本地界面

```powershell
uv run alembic upgrade head
uv run uvicorn app_diagnosis.api.app:create_app --factory --reload
```

打开 `http://127.0.0.1:8000/ui`。真实 Run 会使用 `.env` 中配置的模型并可能产生费用。
