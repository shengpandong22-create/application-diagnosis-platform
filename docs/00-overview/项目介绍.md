# Application Diagnosis Platform 项目介绍

> [返回文档导航](../README.md)

## 项目解决什么问题

普通 LLM Demo 通常只回答“模型说了什么”，本项目还要求系统回答：调用了什么工具、结论依据是什么、引用是否有效、谁确认了结论、过程能否离线回归。

## 三阶段演进

- Phase 0A：有预算、可持久化、工具受控的最小 Agent Loop；
- Phase 0B：脱敏、Evidence、引用校验、人工反馈和审计；
- Phase 0C：离线评测、诊断报告和极简操作界面。

## 核心思想

- LLM 提出候选行动，确定性代码控制权限、预算、Schema 和状态；
- EvidenceDraft 落库后才获得可引用 Evidence ID；
- 模型结论、人工决定、执行记录和审计事件分开保存；
- 自动验收默认使用 Fake/Offline LLM，不访问网络；
- 如实记录架构意图与当前实现妥协。

## 当前边界

项目面向个人单机学习和作品展示，尚未实现 Worker、分布式任务、企业认证、远程日志接入和高可用。
