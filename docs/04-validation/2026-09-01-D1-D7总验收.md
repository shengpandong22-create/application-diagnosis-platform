## 4. 真实模型证据链

1. v1 用 4 条案例建立真实基线，发现 3 条 `LLMTimeoutError`；
2. v2 只把单次超时从 30 秒提高到 60 秒；
3. 连接池案例生成正确根因，但配置 Evidence 不完整；
4. 连接拒绝转为 Agent 总预算耗尽；
5. timeout 的通用关键词造成输入污染，随后用唯一栈帧修复并增加回归测试；
6. 修正样本因重复配置路径探测触发 `max_rounds_reached`；
7. 停止继续调用，将下一步限定为配置候选路径和失败调用去重。

## 5. CI 边界

`.github/workflows/ci.yml` 已建立 push、PR、每日定时和手工触发的离线质量门禁。本地已按同等命令通过；GitHub 首次远程运行需要提交推送后在 Actions 页面确认，不能以本地结果冒充远程 CI 成功。
